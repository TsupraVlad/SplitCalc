# SplitCalc

Консольна програма для розподілу спільних витрат між учасниками групи
(подорож, оренда житла, спільний побут).

## Можливості

- групи учасників з основною валютою;
- витрати з розподілом порівну, у відсотках або в конкретних сумах;
- витрати в різних валютах (UAH, USD, EUR, PLN, власні курси);
- розрахунок балансів з точністю до копійки;
- мінімальний план переказів (не більше n − 1 переказу);
- пояснення балансу учасника, статистика за категоріями, експорт звіту у файл;
- локальне збереження даних у JSON (`~/.splitcalc`), без мережі та облікових записів.

## Запуск

Потрібен Python 3.10+ (лише стандартна бібліотека).

```bash
python -m splitcalc
```
