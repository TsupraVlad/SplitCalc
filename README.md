# SplitCalc

Консольна програма для розподілу спільних витрат між учасниками групи.

- Групи та учасники, витрати з категоріями
- Розподіл порівну, у відсотках або у точних сумах
- Мультивалютність (UAH, USD, EUR, PLN) з конвертацією у валюту групи
- Розрахунок балансів і мінімізація кількості переказів
- Пояснення балансу учасника, звіт у файл
- Збереження груп у JSON (`~/.splitcalc`)

## Запуск

```
python main.py
```

Потрібен Python 3.8+, сторонні бібліотеки не використовуються.

Докладніше — у [керівництві користувача](docs/user-guide.md).
